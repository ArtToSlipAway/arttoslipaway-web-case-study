# ArtToSlipAway — Web Platform Case Study

Public case study for the ArtToSlipAway tattoo and art studio web platform.

The production source code, infrastructure configuration, credentials, customer data and internal integrations are kept in a private repository.

## Stack

- FastAPI
- PostgreSQL
- Nginx
- Docker
- GitHub Actions
- Telegram integration
- AI-assisted client workflows
- CRM and protected client cabinet

## Engineering focus

- backend architecture
- relational data modelling
- authentication and access control
- protected client file delivery
- CRM workflow design
- Telegram ↔ CRM integration
- AI workflow integration
- deployment and Linux administration
- CI and regression testing
- SEO and analytics
